Configuração inicial para comando

Uma base para experimentares no comando — não é apresentada como a configuração oficial de nenhum pro.

OpçãoValor inicial para testarComo ajustar
Modo de sensibilidadeAvançadoAtiva-o se quiseres controlar separadamente a mira e a câmara.
Velocidade horizontal/vertical40–45% / 40–45%Experimenta pequenos passos de 2–3%.
Multiplicador ao apontar (ADS)8–12%Baixa se passares do alvo; sobe se não conseguires acompanhar.
Zona morta dos sticksComeça em 8–12%Reduz até aparecer drift; depois sobe um pouco.
Assistência de miraAtivada, predefinição do jogoNão existe um valor universal que substitua a prática.
Os menus e intervalos podem mudar com atualizações do Fortnite. Usa estes valores apenas como ponto de partida, testa no Criativo e guarda os teus próprios valores. Se já tens boa mira, altera uma opção de cada vez.

Sobre o site

A DropZone FN é um projeto independente de fãs, em português. Fortnite é uma marca da Epic Games. Este site não é afiliado, patrocinado nem aprovado pela Epic Games.

Os dados de settings e drop spots vêm de fontes externas e podem estar desatualizados ou refletir apenas uma amostra de torneios. Confirma as fontes antes de publicar atualizações. Não prometemos ganhos, vitórias ou V-Bucks grátis.
